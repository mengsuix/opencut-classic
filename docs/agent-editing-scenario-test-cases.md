# Agent 日常剪辑场景测试用例

## 1. 测试原则

- 从真实用户的剪辑需求出发，不根据 Agent 当前能力增删用例。
- 除素材准备和结果验收外，所有剪辑操作都通过自然语言交给 Agent 完成，不手动修改时间线。
- 用户指令只描述想要什么，不提示实现方式、工具名称或操作步骤。
- 单轮用例使用全新的项目副本；多轮用例在同一项目中按顺序执行。
- Agent 可以追问。追问是否合理、 clarification 后能否继续完成任务，也计入测试结果。
- 暂不支持、执行错误、结果不符合要求分别记录，不把“未支持”直接算作通过。
- 不以 Agent 的文字回复作为通过依据，必须检查实际画面、声音、时长和前后内容。

## 2. 优先级与结果标记

### 优先级

- **P0**：高频基础需求，应优先保证稳定。
- **P1**：常见成片需求，包含一定的理解、审美或组合操作。
- **P2**：复杂、模糊或长上下文需求，用于检验上限和稳定性。

### 结果标记

- **通过**：结果满足验收重点，且没有明显破坏未要求修改的内容。
- **失败**：尝试执行，但结果错误、不完整或产生明显副作用。
- **未支持**：明确表示无法完成，或核心能力缺失。
- **阻塞**：素材、环境或系统问题导致无法完成测试。

## 3. 建议测试素材

可用等价素材替换，但同一轮大规模测试应尽量固定素材版本。

| 编号 | 素材建议 |
|---|---|
| M1 | 约 5 分钟横屏口播，含停顿、语气词、重复表达和少量说错重说 |
| M2 | 约 15 分钟双人访谈，横屏，话题明确，有主持人提问和嘉宾回答 |
| M3 | 约 3 分钟手机竖屏生活 Vlog，多段素材，含环境声和现场人声 |
| M4 | 约 2 分钟产品素材，无人声，含外观、细节、使用动作和空镜 |
| M5 | 约 20 分钟课程录像，含讲师画面、屏幕或课件，知识点分段明确 |
| M6 | 约 15 分钟游戏录像，含高光操作、等待时间和音量突变 |
| M7 | 约 10 分钟旅行或活动素材，多场景、多镜头，适合混剪 |
| M8 | 约 5 分钟美食制作素材，含步骤、特写、环境声和简单口播 |
| A1 | 约 2 分钟节奏明显的无歌词背景音乐 |
| A2 | 约 2 分钟舒缓、无歌词背景音乐 |
| L1 | 透明底 Logo 图片 |
| P1 | 产品或品牌封面图片 |

如素材实际时长与用例不一致，可按相同语义调整时间点，并在结果中记录实际指令。

## 4. 通用验收标准

1. **完成核心意图**：不仅执行了表面操作，还得到用户想要的内容或观感。
2. **时间点准确**：精确裁剪、插入和删除允许约 ±0.2 秒误差；语义剪辑以内容完整为准。
3. **内容连续**：非用户要求的黑帧、空白、跳帧、重复片段和音画错位均视为问题。
4. **不伤原意**：压缩时长、删除语气词或调整节奏时，不把句子剪断，不改变事实和语义。
5. **无无关变更**：未要求修改的片段、文字、音量、顺序和样式应保持不变。
6. **多轮可继承**：后续修改应保留此前已经确认的结果，只改变本轮要求的部分。
7. **结果可解释**：无法完成、需要补充信息或存在素材限制时，应清楚说明，不假装成功。

## 5. 基础裁剪与镜头整理（001—010）

| ID | 优先级 | 素材 | 用户指令 | 验收重点 |
|---|---|---|---|---|
| AEC-001 | P0 | M1 | “把开头 3 秒剪掉，其他都别动。” | 从原片第 3 秒开始；后续内容、音量和顺序不变；总时长短 3 秒 |
| AEC-002 | P0 | M1 | “结尾最后 5 秒不要了。” | 尾部准确缩短 5 秒；新结尾不突兀、不多删正文 |
| AEC-003 | P0 | M1 | “把 1 分 20 秒到 1 分 28 秒这段删掉，前后接顺。” | 指定中段被删除；拼接处无黑帧、空白和明显音画跳跃 |
| AEC-004 | P0 | M1 | “我只要第 40 秒到第 55 秒，其他全部去掉。” | 只保留目标区间；起点、终点准确；成片约 15 秒 |
| AEC-005 | P0 | M3 | “把现在第二段和第三段换一下，第一段保持不动。” | 仅目标镜头交换；时长和内容不丢失 |
| AEC-006 | P0 | M3、M4 | “把这几个视频按产品外观、使用过程、细节特写的顺序合成一条。” | 顺序符合语义；镜头完整；连接处无空白 |
| AEC-007 | P0 | M1 | “整条视频加速到 1.25 倍，别改别的。” | 全片速度一致；时长约为原片的 80%；声音不严重失真 |
| AEC-008 | P0 | M1 | “把中间没说话的停顿剪短一点，让节奏紧凑些。” | 主要长停顿被压缩；正常语气停顿仍自然；不剪到字词 |
| AEC-009 | P1 | M1 | “按内容把这条视频分成三个部分，每部分单独成一段。” | 分段符合话题边界，不是机械等分；三段内容完整且顺序正确 |
| AEC-010 | P1 | M4 | “最后一个产品定格画面再保留 2 秒，方便放 Logo。” | 结尾自然延长约 2 秒；不重复前文；画面不跳变 |

## 16. 大规模测试汇总建议

每轮测试至少统计：

- 总通过率，以及 P0、P1、P2 分层通过率。
- 单轮需求与多轮需求的通过率差异。
- 精确时间操作、语义内容剪辑、审美类需求各自的通过率。
- 无关修改率、重复执行破坏率、多轮上下文丢失率。
- 未支持率、执行错误率、阻塞率，三者分开统计。
- 每条用例平均耗时、P95 耗时和平均重试次数。
- 相同用例重复执行的结果稳定性。
- 失败案例是否集中在同一素材、同一需求类型或同一修改轮次。
