> 本稿先完成拍摄与剪辑设计。当前 `data/sulphur2/` 目录尚无素材文件，因此状态为草稿；开始剪辑前，须按第 3 节完成素材录制/准备，并把清单状态全部更新为“已就位”。

## 0. 目录约定

```text
data/sulphur2/
  script.md      # 本脚本
  assets/        # 录屏、生成视频、配音、BGM、音效、片尾卡
  export/        # 导出的成片
```

素材路径一律写相对项目目录的路径。

## 0.1 执行约束

1. 本稿不使用工作区界面作为开场钩子，前 4 秒直接展示 Sulphur2 成功生成的视频。
2. 有效信息点控制为 4 个：创建云端实例、Agent 获取示例工作流、Agent 初始化环境、运行时按需调度 GPU 并生成视频。
3. 录屏必须完整保留关键状态变化；等待和初始化过程只做变速，不删掉开始状态与完成状态。
4. 对话框、仓库名称、工作流名称、初始化完成状态、运行按钮和 GPU 调度反馈都必须清晰可读。
5. 录屏中若出现 token、Cookie、个人路径或其他敏感信息，剪辑时必须裁切或马赛克处理。

## 2. 全局设定

### 2.1 配音（VO）

| 项 | 值 |
|---|---|
| TTS 声音 / 模型 | 中文普通话女声 TTS，清晰、可信、偏产品演示口吻 |
| 语速 / 情绪 | 约 6 字/秒；自然、克制，关键结论略加强重音 |
| 文件命名规则 | `assets/vo_shot_001.mp3` 至 `assets/vo_shot_008.mp3`，与镜号一一对应 |

### 2.2 字幕样式

思源黑体 Bold，46~52 px，白字、6 px 黑色描边，底部安全区内居中；每条字幕最多两行，英文和 `GPU` 保持原字母大小写。对话原文作为画面内信息单独保留，不替换旁白字幕。

### 2.3 花字样式预设

| 编号 | 用途 | 样式 |
|---|---|---|
| S1 | 大标题/关键词 | 64~76 px，白字或亮黄色关键词，黑色半透明底，顶部或画面中上部，弹入后保持到信息点结束 |
| S2 | 角标/规则提示 | 24~28 px，白字，右下角安全区，黑色半透明底；只在相关画面出现 |
| S3 | 高亮框/箭头 | 4 px 亮黄色矩形框，白色箭头，跟随录屏中的按钮、状态标签或 GPU 反馈；不遮挡文字 |

| 项 | 值 |
|---|---|

| BGM 音量 / 进点 / 出点 / 结尾淡化 | 全片 18%；旁白出现时压低到 8%；0.0 秒进，47.5 秒出，最后 1.5 秒淡出；选择无歌词、节奏轻快的科技感音乐 |
