# 视频分镜执行脚本 · 模板

> 复制本文件到项目目录，重命名为 `script.md`，逐节填写。
> 填好的标准：**不看任何其他文档，只拿这份脚本 + assets/ 里的文件，就能剪出成片。**

## 0. 目录约定

```
data/<项目名>/
  script.md      # 本脚本
  assets/        # 全部素材：录屏、图片、AI生成、配音音频、BGM、音效
  export/        # 导出的成片
```

素材路径一律写相对项目目录的路径（如 `assets/create-instance.mov`）。

## 0.1 填写规则（硬约束，违反就返工）

1. 脚本里不允许出现 TBD / 待定 / 到时候再说；开剪前素材清单必须全部"已就位"。
2. 素材类型只限五类：`screen_record` / `web_image` / `ai_image` / `ai_video` / `text_card`。
3. 镜头时间码从 0 开始首尾相接、连续覆盖到总时长，不留空隙不重叠。
4. 单镜 2~8 秒；前 3 秒必须是结果/钩子画面（不用工作区界面当钩子）。
5. 有效信息点（不含钩子与 CTA）≤ 4 个，同一卖点不在多镜重复。
6. 成片中段（50%~70% 处）安排一镜回扣开头的结果画面。
7. 旁白按中文 6 字/秒估算，必须念得进镜头时长；旁白不复述画面已可见的操作（如"点击创建"）。
8. 只写常规剪辑手段：裁切、缩放、关键帧推拉、变速、字幕、花字、高亮框、箭头、马赛克、硬切/叠化。不写"特效包""划像"等虚构能力。
9. 合规/计费/规则类表述只进角标字幕，不单独占镜头；无法核验的表述统一写"以产品页面当前规则为准"；AI 生成内容需标注"AI生成"。

## 8. 成片验收 checklist（导出前逐项打勾）

- [ ] 素材清单全部"已就位"，脚本无 TBD
- [ ] 前 3 秒是结果/钩子画面
- [ ] 有效信息点 ≤ 4，无重复卖点

- [ ] 时间轴从 0 连续到总时长，单镜 2~8s
- [ ] 每句旁白都念得进镜头时长（6 字/秒），声画对位准确
- [ ] 旁白不复述画面可见操作
- [ ] 字幕与旁白一致、无错字，在安全区内
- [ ] 合规角标（AI生成/以页面规则为准）已上屏
- [ ] BGM 不压旁白，结尾有淡化
- [ ] 完整看过一遍，无黑帧、无爆音、无错位

## 附：填写示例（一镜，填到这个粒度才算够）

### shot_003 ｜ 创建实例
- **成片时间码**：8.0 ~ 13.5 s（时长 5.5 s）
- **画面素材**：A02（assets/create-instance.mov）
- **素材取段**：入点 2.0 s / 出点 7.5 s
- **变速**：原速
- **画面处理**：缩放到 115% 居中；第 1.2 s 起高亮框圈住「新建实例」按钮（S3）；第 2.8 s 关键帧放大到 GPU 下拉菜单区域 160%
- **转场**：硬切
- **旁白**：「不用买显卡，不用装环境，浏览器里点一下，实例就是你的。」（18 字 ≈ 3.0 s，放得下）
- **VO 文件**：assets/vo_shot_003.mp3
- **声画对位**：念到「点一下」时，画面正点击「新建实例」按钮
- **字幕**：同旁白
- **花字**：S1「浏览器一键创建」顶部居中，相对时间 0.5~5.0 s，弹入；S2「价格以产品页面当前规则为准」右下角常驻
- **音效**：1.2 s 处轻提示音（assets/sfx_pop.mp3）
- **备注**：按钮点击瞬间前后各留 0.3 s 余量，别剪太紧
